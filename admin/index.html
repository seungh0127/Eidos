Module Color Admin

Adjust brightness / contrast / saturation for the main-page module thumbnails and videos. Changes apply instantly — including live in the main site if it is open in another tab of this browser.

How to make this the permanent site default

These values are saved to this browser only (localStorage), so they preview live but are not visible to other visitors. To ship them as the new default for everyone, copy the CSS values above and set them as the :root defaults in styles/main.css (--mod-brightness, --mod-contrast, --mod-saturate), then commit.
